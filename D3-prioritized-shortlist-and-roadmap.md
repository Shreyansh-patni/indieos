# D3 — Prioritized Keyword Shortlist, Launch Batch and Publication Roadmap

**Research date:** 2026-10-23 · **Database:** D2 (220 records, 57 P1) · **Scheduling detail:** full week-by-week rows for all 47 scheduled articles are in `research/track-roadmap.md`; cluster and linking logic in D5; SERP evidence in D4.
**How to read the priorities:** P1/P2/P3 come from a transparent prioritisation framework (composite = 0.25·Relevance + 0.15·Intent fit + 0.20·Demand evidence + 0.20·Competition feasibility for a brand-new domain + 0.10·Effort inverse + 0.10·Cluster/evergreen value; P1 ≥ 3.80). The composite orders work; it does NOT predict rankings. Demand evidence is SERP-based because no free tool could return volume/KD/CPC data in this environment (see D1 §4). Where the live-SERP verdict (D4) contradicts a high score, the SERP verdict wins — that is why some P1s are deliberately scheduled late.
